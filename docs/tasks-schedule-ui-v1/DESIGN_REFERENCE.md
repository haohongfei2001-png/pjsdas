## 不可丢失的构图与行为

- 顶部三个平级导航：今天、岗位库、日程。右侧全局告诉PJSDAS和低频设置。没有可见快捷键。
- Today是两个整体面板：任务约58%、节点约42%，首部对齐。当前原型普通desktop为1.4:1，宽屏略收为1.35:1；允许为可读性微调，不能回到右侧微缩Agenda。
- 左侧所有任务同一行结构：公司→岗位→真实时间约束→明确动作。无首项hero、排名宣言、预计时长、时间预算、最近处理模块、常態同步延迟。
- 节点右栏独立滚动，按真实日期分组，已有节点逐批到末尾。过去待确认是简短入口，不堆在未来首屏。
- 手机和大字转为Today局部“任务/节点”切换，不把双列缩小；全局仍是三入口。
- 岗位库是长期岗位集合，不是第二份今日清单；搜索/筛选一组，列表精简，完整内容点击进入页面详情。
- 日程是过去/待确认/未来的一份业务时间线；默认定位今天附近；Today右侧是它的未来子集。
- 详情承载完整角色名、行动原因、阶段、来源、材料、申请约束和历史。无关联数据则不制造占位说明墙。
- 全局输入是简洁录入，不是聊天主页；具体解释结果、目标身份和确认仍需存在。原型的设置→设计验证不会出现在生产。

## 原型与真实产品的差别

原型使用内存合成数据、固定时钟和模拟保存/撤销，只证明交互提案可浏览。它没有生产服务器分页、真实账户、持久化事务、live来源或真实辅助技术证据。生产必须接当前仓库的 domain command / receipt / Undo / source identity，不能用SEED数组或假计时器替代。

三轮原型评审记录是设计历史；实施必须再做至少三轮真实组件的视觉闭环。新阶段只实现已认可目标，不借“重新思考功能”扩展为通用日历、项目管理或自动求职代理。
