## 第一轮：实际截图与批评

- head `c4f402b2f4ff4d611a2878518ddf5364b5f1be46` 的 Browser E2E [36131004286](https://github.com/haohongfei2001-png/pjsdas/actions/runs/36131004286) 为 75 passed / 1 个测试 selector 严格匹配错误；截图已从该 run 日志核对，不将整批写作 PASS。
- 桌面“全部”已从今天日期组开始，过去、未来和未确认/时间待定事实可达；手机未横向溢出。现有高优先级问题：旧高特异性 CSS 将日程扩到约 1320px，超过认可基准约 1120px；每日一项夹具时日期组与行叠加显得过高；点击事件后详情实际渲染在长列表底部，用户首屏看不到。
- 修正：覆盖高特异性 max-width；压缩仅由空白带来的行高；把详情置于列表之前并将键盘焦点/滚动移到详情，关闭后回到原事件行；日期组已标出日期，行内仅显示真实时间精度。月定位/今天定位与旧回填完成时间过滤保留。
- 唯一浏览器失败是新用例 `.settings-surface h1` 同时匹配设置页标题与折叠规则组件中的 h1；改为只选择页面标题。后续截图会包含事件详情、录入及设置手机实际状态。
