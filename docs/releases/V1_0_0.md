# PJSDAS v1.0.0

PJSDAS v1.0.0 is the first formal public release of the Personal Job Search Decision & Action System.

It packages the previously developed v1.x engineering milestones into one production-verified product release. The product is designed to answer one operational question quickly: **what should I do next for my job search?**

## Product surface

- **Today** — concrete next actions under deadline, timing, leverage, and available-time constraints.
- **Decide** — Opportunities and the real recruiting Pipeline without turning passive system maintenance into user work.
- **Prepare** — reusable preparation inventory plus deterministic Prep Graph leverage.
- **History** — factual Timeline and ChangeSet audit history.
- **Settings** — account/sync, Discovery Profile, Decision Rules, backup/recovery, AI access, and language.

## Decision and data model

- deterministic ranking after interpretation;
- explicit user-controlled Decision Rules;
- source-backed canonical job identity;
- component-level Fit and Opportunity Value assessment;
- Application Portfolio decisions for shared application quotas;
- Process Events and Actions kept as durable, auditable state;
- local IndexedDB workspace with optional private Google Drive `appDataFolder` synchronization;
- optimistic workspace-version protection against silent concurrent overwrite.

## AI and automation

- authenticated MCP read surface for Today, Opportunities, Pipeline, Decision Rules, assessment explanations, Application Portfolio, Prep Graph, discovery context, Coverage, and Workspace Integrity;
- generic AI changes remain review-only through signed ChangeSets;
- bounded trusted Monitor and Gmail ingestion can autonomously apply source-backed factual updates;
- ambiguous identity fails closed rather than guessing;
- ingestion is reconciliation-accounted and idempotent.

## Reliability

v1.0.0 includes the v1.10 autonomous reliability workstream:

- synthetic/golden workspace scenarios;
- seeded reproducible state-machine stress tests;
- adversarial ingestion matrices;
- Drive/sync/replay/concurrency fault injection;
- Chromium end-to-end critical journeys;
- workspace integrity and source-health auditing;
- backend/frontend exact Git commit binding;
- accountless production MCP tool-surface proof;
- backend-first Pages release gating;
- post-deploy Production Self-Test.

The release process is fail-closed: GitHub Pages is published only after the production backend for the same commit advertises the required health, capability, authentication-boundary, and MCP release-tool-surface contract.

## Versioning note

The public product release is `v1.0.0` and `package.json` is `1.0.0`.

Historical `v1.9` / `v1.10` labels are engineering milestones rather than public Semantic Versioning releases. The authenticated MCP runtime currently remains `1.9.0-alpha.1` as an independently versioned compatibility contract.

See `docs/RELEASE_POLICY.md` for the permanent versioning and release rules.
