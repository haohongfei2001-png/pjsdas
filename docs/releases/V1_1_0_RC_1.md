# PJSDAS v1.1.0-rc.1

Release channel: **prerelease / owner-canary candidate**

This candidate packages the completed Round 0–4 AI-operated production architecture for final hardening before owner canary.

## Candidate scope

- AI-operated mutation contract with bounded P1 Domain Commands and governed P3 changes.
- Transactional connected-workspace foundation with revision/CAS, command ledger, receipts, idempotency, and compensation metadata.
- Gmail complete-consumption continuation so durable cursors never advance past unconsumed pages/ids.
- Independently verified Discovery source evidence before source facts may create or refresh Opportunities.
- Web console IA: Today / Opportunities / Attention / Activity / Settings.
- Controlled audience foundation with owner/beta grants.
- Canonical Web/API topology inputs, legacy-origin protection, and explicit connected migration workflow.
- Exact-SHA deployment gates across Vercel, GitHub Pages, and post-deploy self-test.

## RC hardening additions

- Product version, commit SHA, MCP contract hash, migration-set hash, and snapshot compatibility are bound into the backend release contract.
- The Pages build emits a frontend release manifest with an artifact digest.
- Production verification compares frontend and backend release identity before a candidate is considered deployable.
- GitHub prerelease publication is gated on repository-level Immutable Releases being enabled.
- Migration/cutover/recovery rehearsals must pass before publication is armed.

## Deliberately not activated by this candidate build

- No public signup.
- No automatic external job submission/withdrawal.
- No automatic recruiting email sending.
- No Offer acceptance/rejection.
- No owner workspace migration without explicit owner action.
- No transactional authority switch without verified migration and cutover gates.
- No allowlist switch without an owner grant.
- No guessed canonical personal domain.

## Canary intent

If this RC passes Round 5 go/no-go, Round 6 uses the exact tagged candidate for owner canary before any controlled beta or stable v1.1.0 publication.
