# CGR-04 — Natural Intake & Automation Closure

State: **BLOCKED — NOT_STARTED**

## User-visible outcome

Web and authorized sources accept natural updates with specific truthful outcomes; transport health, understanding failure, business ambiguity and normal capability boundary are distinct.

## Scope

- One contextual interpretation result contract upstream of Semantic Intake.
- Unify Web/Gmail/PAIA-current-chat context/candidates/feedback.
- Improve real language and identity/occurrence resolution.
- Preserve source original versus interpretation distinction.
- Separate transport/interpretation/ambiguity/capability states.
- Make coverage UX reflect business impact/freshness.
- Only claim source/delivery capability with live end-to-end proof.

## Non-goals

- No model independent write authority.
- No new private-data transmission/cost/permission without owner decision.
- No capability completion by flag/unsupported response.
- No external recruiting authority.

## Preserved invariants

- Opportunity / Process / Action / Prep semantics remain authoritative.
- ScheduleNode occurrence/version identity and temporal precision remain authoritative.
- Deterministic Decision Rules/ranking remain single-source domain logic.
- Semantic Intake policy, DecisionRequest, provenance and source authorization are not bypassed.
- Supabase transactional workspace remains connected-mode authority.
- CAS, command ledger, receipts, idempotency and exact-SHA/security gates remain mandatory.
- No external application/withdrawal/email/Offer authority is added.

## Architecture changes

- Source acquisition → contextual interpretation → candidates → deterministic policy → authoritative command.
- Transport reliability remains separate from semantic interpretation quality.

## Migration

- Run new interpreter alongside old without double-write; compare then migrate source-by-source.
- Preserve Gmail cursor/lease/replay and source identities/receipts.

## Legacy retirement

- Retire duplicated source-specific business transitions.
- Retire generic unresolved counters conflating capability boundaries.
- Keep deterministic helpers where valuable.

## Required tests

- Quoted reschedule mail updates one current occurrence and preserves history.
- Equivalent authorized PAIA/current-chat and Web statement reach same business outcome when source active.

- Transport failure shows freshness impact/recovery.

- Coverage and critical errors both reported.
- Transport/interpretation/ambiguity/capability states separate.
