# CGR-05 — Consumer-Grade Certification

State: **BLOCKED — NOT_STARTED**

## User-visible outcome

A stable consumer-grade Web baseline is certified: coherent daily workflow, trustworthy authority/recovery, high visual completion, responsive/accessibility quality, account isolation, production evidence and retired legacy daily paths.

## Scope

- Absolute feature freeze.
- Realistic dense workspace.
- Cross-client/device and long sessions.
- Failure/degraded recovery.
- Visual regression/craft.
- Responsive/large text/keyboard/screen reader.
- Account isolation.
- Exact-SHA production canary.
- Final legacy retirement.

## Non-goals

- No new features/sources/automation modes/major architecture.
- No native iPhone/UU-08.
- No release publication without separate authorization.
- No gate weakening.

## Preserved invariants

- Opportunity / Process / Action / Prep semantics remain authoritative.
- ScheduleNode occurrence/version identity and temporal precision remain authoritative.
- Deterministic Decision Rules/ranking remain single-source domain logic.
- Semantic Intake policy, DecisionRequest, provenance and source authorization are not bypassed.
- Supabase transactional workspace remains connected-mode authority.
- CAS, command ledger, receipts, idempotency and exact-SHA/security gates remain mandatory.
- No external application/withdrawal/email/Offer authority is added.

## Architecture changes

- No new direction; only hardening/simplification/retirement needed to satisfy frozen target.

## Migration

- Finish bounded compatibility migrations and prove no new client relies on retired paths.

## Legacy retirement

- Remove obsolete app shells/entrypoints, CSS/polish layers, ordinary whole-snapshot mutation and obsolete authority UX.
- Document intentionally retained recovery/export paths outside daily UX.

## Required tests

- Full domain suite.
- Full continuous journeys.
- Dense/performance/long-session.
- Cross-client/uncertain network.
- Visual matrix.
- Responsive/large text/keyboard/screen reader.
- Account isolation/security.
- Production canary + rollback rehearsal.

## Continuous real-user journeys

- Full daily Today→opportunity→natural update→decision→schedule/history.
- Two clients + source update without lost/duplicate facts.
- Long session/background refresh without drift.
- Offline restart then exact-once recovery.
- Account A→sign out→B with zero A render/upload.
- Source failure/recovery freshness.
- Undo/correction after unrelated/dependent changes.

## Visual / responsive evidence

- Approved references for all primary/degraded/empty/dense states.
- Phone/intermediate/wide layouts.
- Long bilingual, 200% zoom/large text, keyboard and screen-reader.
- No uncontrolled legacy CSS.

## Production evidence

- Exact-SHA complete daily canaries on todayaction.com.
- Security/auth/migration/deploy gates green.
- Measured product targets satisfied or objective thresholds frozen before run.
- Publication remains separate owner decision.

## Failure / degraded scenarios

- Session expiry mid-command.
- Lost response after commit.
- Offline restart.
- Source outage/revoke.
- Partial backend/read failure.
- Dense history.
- Cross-account switch.
- Screen-reader/keyboard flow.
- Rollback rehearsal.

## Rollback

- Demonstrate bounded client/surface rollback and source kill switches without stale snapshot restore.
- Certification failure keeps phase open; never reactivates retired unsafe paths just to pass.

## Exact exit criteria

- No critical correctness/authority/account-isolation/recovery blocker in canonical journeys.
- Primary surfaces meet visual/responsive/accessibility baseline.
- Dense/long-session evidence green.
- Cross-client/production canaries green on exact runtime.
- Legacy daily UI/CSS/write paths removed or explicitly bounded recovery-only.
- Completion report states stable capabilities/known limits before technical evidence.
- Only then may owner be asked whether to reopen iPhone/UU-08.

## Owner decision points

- Owner gives final baseline acceptance and any later release/iPhone/UU-08 decision. Ordinary certification fixes remain delegated.
