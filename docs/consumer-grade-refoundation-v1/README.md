## Purpose

This package is a bounded refoundation of PJSDAS product delivery. It is not a Product Reset and it does not discard the existing domain, transactional, provenance, authorization, or release foundations that are already correct.

The problem is that PJSDAS has accumulated many correct parts without yet making the complete everyday product sufficiently natural, reliable, coherent, visually finished, and trustworthy.

The target is a stable consumer-grade baseline in which the product continuously maintains job-search reality from trusted sources, presents the right next action and near-term commitments, makes ordinary complexity disappear, and asks the owner only for genuine human decisions.

## Completion doctrine

A phase is not complete because code exists, a contract exists, tests pass, a page renders, or a previous roadmap called a related feature complete.

The first completion question is:

> What can the user now complete reliably that they could not reliably complete before this phase?

Only after that answer is supported by journey, failure, visual/responsive, and production evidence may implementation and CI evidence close the phase.

## Prototype doctrine

This package does not authorize a disposable, fully implemented prototype that is later thrown away.

Target composition, interaction rules, visual references, and acceptance evidence may be frozen before implementation. Production development then proceeds through production-grade vertical slices so design learning is incorporated into the final system rather than duplicated in a parallel prototype.

## Owner role

The executor owns ordinary product design, interaction design, visual-system decisions, software architecture, implementation tradeoffs, debugging, accessibility, and test design.

Owner approval is required only for product-value tradeoffs, irreversible data or permission changes, new costs or paid commitments, privacy/legal boundaries, external consequential actions, or genuinely different product directions with no objective superiority.
